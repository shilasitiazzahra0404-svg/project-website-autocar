PROJECT SISTEM INFORMASI PENJUALAN KENDARAAN
============================================

1. Ekstrak folder "penjualan_kendaraan" ke:
   C:\xampp\htdocs\

2. Pastikan database:
   db_penjualan_kendaraan

3. Jalankan Apache dan MySQL dari XAMPP.

4. Buka:
   http://localhost/penjualan_kendaraan/

5. Tes koneksi:
   http://localhost/penjualan_kendaraan/test_koneksi.php

6. Login:
   Admin:
   email: admin@gmail.com
   password: admin123

   Sales:
   email: sales@gmail.com
   password: sales123

CATATAN:
- Customer tidak login dan tidak registrasi.
- CSS dipisahkan ke assets/css/style.css.
- JavaScript dipisahkan ke assets/js/.
- Data transaksi menggunakan database yang sudah dibuat.
- Sebelum transaksi Sales, pastikan user Sales sudah memiliki baris pada tabel sales dengan id_user yang sesuai.
